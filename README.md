## What I'm working on
### 🛒 TrashNSell
A full-stack business operations platform built for a junk removal company. Features a price estimation engine, job management, applicant tracking, automated invoicing through the Square API, and integrations with Google Places and Google Calendar.

### 🃏 PonyCCG
A full-stack, Discord-native collectible card game platform built around the My Little Pony: CCG ruleset. Features automated card ingestion, Discord OAuth deckbuilding, and an LLM-assisted pipeline that transforms human-readable card abilities into validated, structured game mechanics using JSON schemas. Currently in development.

### 🌐 TranslateYourReviews
A browser extension that adds DeepL translation support to reviews on [Rate Your Music](https://rateyourmusic.com). Written with TypeScript and available on the Chrome Web Store as well as Firefox Add-ons Store.
